Clash Verge Rev使用教程：下载、导入订阅与连接

lo52026-09-11— 次阅读
使用教程

Clash Verge Rev 是电脑端代理客户端，支持 Windows、macOS 和 Linux。完成连接需要三样东西：适合系统的客户端、可用的订阅配置，以及在客户端中选好节点并开启代理。本教程按这个顺序操作，并说明导入失败、节点超时和网页打不开时先查什么。

本文使用本站已有截图演示，界面名称可能随版本变化；下载入口与项目说明核对日期为 2026 年 10 月 28 日。客户端本身不提供机场套餐，订阅需要由你使用的服务商提供。

一、从项目官方入口下载

打开 Clash Verge Rev 官方项目发布页，根据系统和处理器选择安装包。安装要求与具体步骤以项目文档为准。

电脑类型 选择时检查什么
Windows 在系统“关于”中查看系统类型，区分 x64 与 ARM64；选择对应安装程序
Apple 芯片 Mac 查看标有 Apple Silicon、ARM64 或 aarch64 的 macOS 安装包
Intel 芯片 Mac 选择适用于 Intel / x64 的 macOS 安装包
Linux 同时核对处理器架构、发行版和软件包格式，按官方安装说明操作

下载页面的 Source code 是源码文件。普通使用应选择对应系统的应用安装包。遇到系统提示时先核对下载来源、系统兼容性及官方说明；不要为安装软件而关闭整台设备的安全保护。

还没有选好客户端，可查看电脑和手机客户端下载入口。

二、导入服务商提供的订阅

登录服务商用户中心，找到“订阅”“一键导入”或“复制订阅”入口，选择适用于 Clash 的格式。服务商首页、邀请注册链接和个人订阅地址用途不同，只有正确的订阅地址才能加载配置。

方法 A：使用一键导入

如果后台提供 Clash Verge Rev 或兼容客户端的导入选项，可以点击后允许浏览器打开客户端，再按提示确认导入。

如果按钮没有唤起软件，改用手动复制订阅，不必反复重装客户端。

方法 B：手动粘贴订阅地址

  1. 在服务商后台复制适用于 Clash 的订阅链接。
  2. 打开 Clash Verge Rev 的“订阅”页面，将完整链接粘贴到导入位置。
  3. 导入后确认配置已经下载，并将这份配置设为当前使用的订阅。
  4. 打开“代理”页面，检查是否出现节点或策略组。

订阅链接可能包含账户访问凭据，不要公开到评论区、截图或论坛。链接失效时，先在服务商后台检查套餐是否有效、流量是否用完，以及是否需要重新复制地址。

三、选节点，开启系统代理

在“代理”页面展开与你的配置有关的策略组，选择需要使用的节点。日常可从“规则”模式开始，再核对常用网站是否按预期连接。

延迟数字只反映本次探测条件下的响应情况。先固定一个节点打开常用网页或应用，再判断是否适合自己；不要仅凭最低延迟就认定速度和稳定性最好。

在设置中开启“系统代理”。项目文档说明，系统代理通过修改操作系统的代理设置，满足许多浏览器访问场景；不使用系统代理的程序可能需要另外配置。TUN 会通过虚拟网卡接管流量，是否启用应结合你的应用需求和官方教程判断。官方快速入门

不要把“软件已启动”“系统代理已开启”和“目标应用已经可用”视为同一件事。完成设置后，重新打开目标页面或建立新连接，并查看客户端连接记录。

四、规则、全局、直连怎么选？

模式 对进入客户端的连接如何处理
规则 Rule 按配置中的规则选择代理、直连或其他处理方式
全局 Global 统一交给 GLOBAL 策略处理，仍需查看选中了什么节点或策略
直连 Direct 使用本机网络直接访问目标，不经本客户端的代理节点

规则模式是否做到某些网站直连、某些网站代理，取决于配置内容。全局模式也不等于自动接管电脑上的所有程序。需要详细解释，可阅读规则、全局、直连与流量消耗。

五、连接失败，按现象排查

现象 先检查什么
订阅导入报错 地址是否完整、格式是否适用于 Clash、套餐是否有效；保留报错文字
导入成功却没有节点 是否选中了正确的配置，订阅是否更新成功，服务商是否返回有效内容
全部节点超时 本地网络、服务公告、账号状态与客户端日志；换一个网络作对照
只有浏览器可用，某个程序不行 该程序是否使用系统代理，是否有独立代理设置；再按官方教程考虑 TUN
延迟低但下载慢 测试相同任务，核对目标服务器、节点吞吐量和网络波动
退出客户端后网络异常 检查系统代理是否已关闭，再检查系统网络设置

一次只改一个条件，保留能恢复的原配置，更容易知道是哪一步起了作用。持续异常时查看节点在线但网页打不开的排查步骤，或延迟低但速度慢的对照方法。

安卓手机使用方法见 Clash Meta 安卓教程；尚未获取订阅，可先读从购买订阅到电脑手机连接的图解。
