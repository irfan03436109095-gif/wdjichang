使用教程

按你的设备选择一款客户端，再导入服务商提供的对应订阅，即可开始配置连接。下面整理了 Windows、macOS、安卓、iPhone / iPad 和 Linux 的常用下载入口。

下载入口核对日期：2026 年 10 月 15 日。 直达安装包采用本次核对的正式版本，其他版本和后续更新请查看对应项目的官方发布页。客户端安装后，还需要自己的有效订阅或节点配置。

安装包怎么选？

Windows

在“设置 → 系统 → 系统信息 / 关于”中查看系统类型。常见 Intel、AMD 64 位电脑选择 x64 / amd64；使用 ARM 处理器的设备选择对应的 arm64 构建。具体支持的 Windows 版本以项目说明为准。

新手可以使用上表的 Clash Verge Rev 安装包，按照安装向导操作。下载页若同时提供安装版与便携版，.exe 通常用于安装，.zip 便携包需要先完整解压再运行；不同工具的依赖要求以发布说明为准。

macOS

打开“苹果菜单 → 关于本机”：显示 Apple M 系列芯片时，选择 arm64 / aarch64 / Apple Silicon；显示 Intel 处理器时，选择 x64 / amd64 / Intel。

本页提供 Clash Verge Rev 两种芯片的 .dmg 入口。Hiddify、FlClash 和 v2rayN 的其他 Mac 构建可从各自官方发布页获取，安装前确认当前 macOS 版本在支持范围内。

安卓 Android

普通安卓手机可以先核对是否适用 arm64-v8a 安装包；较旧的设备或模拟器可能需要其他架构。FlClash 和 v2rayNG 的官方发布页提供不同架构的 APK，Hiddify 的本次发布还提供通用 APK，按设备与官方说明选择即可。

本页快速入口使用 FlClash ARM64 APK。如果服务商提供的是 v2rayNG 教程，可以直接从上表进入 v2rayNG 发布页，并阅读其安卓安装包说明。

iPhone / iPad

通过上表的 Shadowrocket App Store 入口查看应用。商店列出的开发者为 Shadow Launch Technology Limited，购买价格、地区可用性及最低系统版本以你看到的商店页面为准。

安装后，在服务商后台选择 Shadowrocket 对应的订阅或导入方式。应用费用与机场套餐费用分别计算，购买客户端本身不会自动获得机场节点。

Linux

先确认发行版和处理器架构，再选择项目提供的安装格式：Debian、Ubuntu 等系统可查看 .deb，Fedora 等系统可查看 .rpm；提供 AppImage 的项目，可按其说明使用对应构建。

本页给出 Clash Verge Rev 的 x64 DEB / RPM 直达入口。ARM64 或其他发行格式，请通过官方发布页查看当前可用包与依赖说明。

下载后，按这个顺序开始使用

  1. 安装客户端。 选择与你的设备、系统版本和订阅要求匹配的软件。
  2. 复制对应订阅。 在服务商后台找到“我的订阅 / 一键导入 / 复制订阅”，选择该客户端支持的格式。
  3. 导入并更新节点。 确认客户端显示节点列表，以及套餐仍有流量、处于有效期内。
  4. 选择模式与节点。 日常可从规则模式开始；根据客户端教程开启系统代理或 VPN / TUN 连接。
  5. 验证常用任务。 先打开日常网页或应用，确认连接正常，再按需要调整节点与规则。

需要完整图解，可以阅读本站的新手机场订阅与电脑手机连接教程。不清楚模式区别时，查看规则、直连、全局与流量消耗说明。

常见问题

GitHub 页面打开了，安装包在哪里？

进入对应版本的 Assets（资源） 列表，按系统、架构和文件后缀选择。Source code (zip / tar.gz) 是源码包；普通安装应选择项目发布的 EXE、DMG、APK、DEB 等应用包。优先使用正式发布版本，测试版和开发构建按项目说明选择。

软件装好了，为什么没有节点？

客户端负责读取配置和建立连接。安装完成后，需要导入你自己的有效订阅或节点配置；免费客户端与服务商是否收费、是否提供试用，是分别确认的事项。

订阅导入失败，先检查什么？

检查是否选对了客户端对应格式、链接是否复制完整，以及客户端版本是否支持当前协议。然后按服务商最新教程更新订阅。不同客户端支持的协议、分流规则和配置格式可能不同。

工具更新后，从哪里获取新版？

使用本页“常用客户端官方下载”表中的最新正式版入口，或客户端提供的官方更新功能。本页的直达包便于下载本次核对的版本，项目后续发布的新版本可在对应官方发布页查看。

本站整理下载入口与使用说明，安装包来自软件项目官方发布页，iOS 应用来自 App Store。
